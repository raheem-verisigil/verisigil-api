Engineering Observation
Root Cause — CHG-011 NameError
The regression originated from a NameError introduced during the no-authentication refactor. Specifically: the function signature was updated to remove auth parameters, but the internal function body still referenced the previous authentication helper (require_api_key) — undefined variables in scope. Result: internally the code appeared correct; the public endpoint failed only under no-auth conditions — invisible to internal review.
"A signature updated during the no-auth refactor while the body still called the old auth helper is exactly the class of bug that only shows up from the outside, because internally the code still reads correctly. That is the argument for having someone hit the public surface with no key on every deploy, not just at the end of a cycle."
— Alkama Eqbal, independent reviewer · 2026-08-07
